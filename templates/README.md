# Reusable blank workpapers

Copy, rename and fill these originals; they contain prompts and example columns, no real personal data. Each workpaper asks for owner, evidence and review date. They are not certifications or legal advice.

| Workpaper | Main use |
|---|---|
| [System card](system-card.md) | Purpose, boundary, affected people, model/system versions |
| [Inventory](ai-inventory.csv) | Portfolio and shadow AI triage |
| [Risk register](risk-register.csv) | Harm scenarios, treatment and residual risk |
| [AI impact assessment](impact-assessment.md) | Rights, societal and stakeholder effects |
| [Evaluation plan](evaluation-plan.md) | Pre-registered claims, metrics and uncertainty |
| [Threat model](threat-model.md) | Attack surface, boundaries and negative tests |
| [Vendor due diligence](vendor-due-diligence.md) | Evidence requests and shared responsibility |
| [Audit workpaper](audit-workpaper.md) | Criteria, sample, evidence and findings |
| [Incident runbook](incident-runbook.md) | Triage, containment, communications and recovery |
| [Governance charter](governance-charter.md) | Decision rights and reviews |
| [Control evidence matrix](control-evidence-matrix.csv) | Cloud/AI control owners, tests, exceptions and evidence |
| [Assurance scope note](assurance-scope-note.md) | CAIQ, STAR, SOC 2 and certificate scope and limitations |
| [Board risk brief](board-risk-brief.md) | COSO strategy, risk appetite, control and board decision |
