# GOV 310: Foundations of AI Governance and Responsible Use

Decide whether and how an AI system should be used, identify affected people, govern risk, and document accountable decisions.

[Teach this course](syllabus.md) · [Instructor guide](instructor-guide.md) · [Assignments](assignments.md) · [Assessments](assessments.md) · [Common case](../../shared/case-campusassist.md) · [Resource catalog](../../shared/resources.md)

## Learning outcomes

1. Define an AI system boundary, its intended use, actors, and lifecycle.
2. Compare principles, voluntary frameworks, management-system standards, and binding law without confusing their authority.
3. Build an inventory and risk register for an AI use case.
4. Conduct a structured impact assessment with affected-stakeholder participation.
5. Write a governance charter, use policy, and justified go/no-go decision.
