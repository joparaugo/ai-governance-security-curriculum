# Midcourse assessment bank and public key

Use these as formative items or change facts for summative use. Suggested time: 60 minutes; eight multiple-choice items (5 points each) and two short response items (30 points each). Allow open publisher sources but require justification and denominators.

## Student questions

**1.** An evaluation claim becomes testable when it specifies:

- A. A glossy dashboard
- B. Population, metric, threshold and version
- C. Only accuracy
- D. Vendor reputation

**2.** Testing repeatedly on the same holdout chiefly risks:

- A. Better consent
- B. Overfitting the test set
- C. More privacy
- D. Larger groups

**3.** False negative rate has denominator:

- A. All predicted negatives
- B. Actual positives
- C. All samples
- D. False positives

**4.** Which is essential for a group comparison?

- A. Only percentage
- B. Numerator and denominator for each group
- C. No positive class
- D. A claim of parity

**5.** A clean file with biased labels is:

- A. Automatically valid
- B. Still subject to construct and measurement bias
- C. Legally certified
- D. Equivalent to field evidence

**6.** Best reason to conduct a field study?

- A. It replaces all offline tests
- B. It can observe workflow and human effects absent from offline tests
- C. It proves causality automatically
- D. It needs no consent

**7.** A chatbot safety pass rate without case mix:

- A. Has clear meaning
- B. Needs test-set composition and adjudication criteria
- C. Is always 100%
- D. Proves fairness

**8.** Rising complaints with stable accuracy suggest:

- A. No action
- B. Investigate monitoring blind spots and impacts
- C. Immediate retraining without analysis
- D. Discard complaints

**9. Short response (30 points).** For TP=8, FN=2, FP=5, TN=17, calculate recall and precision. Show reasoning and one source or case reference.

**10. Short response (30 points).** Propose one metric and one qualitative method for assessing advisor over-reliance. Show reasoning and one source or case reference.

## Instructor key and scoring notes

- 1: **B**. A threshold and defined context permit a falsifiable test.

- 2: **B**. Repeated selection inflates apparent performance.

- 3: **B**. FNR = FN/(TP+FN).

- 4: **B**. Small counts can make rates unstable.

- 5: **B**. Data cleanliness does not establish label validity.

- 6: **B**. Field testing addresses contextual impact under appropriate safeguards.

- 7: **B**. The denominator and case selection determine interpretation.

- 8: **B**. Aggregate accuracy can hide harms and label delay.

- 9: Recall 8/10=0.8; precision 8/13≈0.615; state positive class. Award 10 points for method, 10 for correct application, 5 for uncertainty and 5 for a cited anchor or case evidence.

- 10: Accept override review, time-on-task or calibration plus observation/interview, with privacy safeguards. Award 10 points for method, 10 for correct application, 5 for uncertainty and 5 for a cited anchor or case evidence.

**Item analysis:** after class, record which distractors attracted learners and revise ambiguous wording. Never infer competence from these ten items alone; use applied artifacts and defense.
