# AIE 420: AI Assurance, Data Governance, and Evaluation

Design defensible tests, evaluate data and system behavior, document uncertainty, and produce auditable assurance evidence.

[Teach this course](syllabus.md) · [Instructor guide](instructor-guide.md) · [Assignments](assignments.md) · [Assessments](assessments.md) · [Common case](../../shared/case-campusassist.md) · [Resource catalog](../../shared/resources.md)

## Learning outcomes

1. Set measurable claims, thresholds and valid evaluation designs.
2. Assess data provenance, quality, privacy and leakage.
3. Calculate and interpret group performance with uncertainty and subgroup limits.
4. Test generative systems for harmful output, robustness and human impact.
5. Build a reproducible assurance dossier and monitoring plan.
