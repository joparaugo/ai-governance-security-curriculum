# Midcourse assessment bank and public key

Use these as formative items or change facts for summative use. Suggested time: 60 minutes; eight multiple-choice items (5 points each) and two short response items (30 points each). Allow open publisher sources but require justification and denominators.

## Student questions

**1.** Retrieved webpage text is best treated as:

- A. System instruction
- B. Untrusted data
- C. Tool permission
- D. Developer policy

**2.** Where should a send-email decision be enforced?

- A. Only in the model prompt
- B. At an independently checked tool authorization boundary
- C. In the page source
- D. In a marketing statement

**3.** Which is a training integrity control?

- A. Unversioned dataset
- B. Provenance, approval and immutable versions
- C. No holdout
- D. Open tool access

**4.** A model registry hash helps verify:

- A. Fairness
- B. Artifact identity
- C. Legal compliance
- D. All user permissions

**5.** ATLAS is primarily:

- A. A certification body
- B. An adversarial AI threat knowledge base
- C. An EU regulation
- D. A privacy law

**6.** What is a good negative test?

- A. The system works once for admin
- B. An unassigned advisor is denied private-note retrieval
- C. The vendor says secure
- D. The model answers fluently

**7.** A prompt filter alone is insufficient because:

- A. All prompts are harmless
- B. Authorization and tool controls must also hold
- C. No logs are needed
- D. Data cannot leak

**8.** Fourteen blocked emails imply:

- A. No investigation
- B. Investigate attempts, root cause and any successful actions
- C. Automatic compliance
- D. No need to preserve logs

**9. Short response (30 points).** Write an allow rule for an advisor retrieving a student note. Show reasoning and one source or case reference.

**10. Short response (30 points).** Name one prompt-injection test and one ordinary web-app test for the same workflow. Show reasoning and one source or case reference.

## Instructor key and scoring notes

- 1: **B**. Retrieved content must not confer authority.

- 2: **B**. The tool must enforce caller, target and action permission.

- 3: **B**. Traceable ingest and separation of duties address poisoning.

- 4: **B**. It can show which artifact was deployed.

- 5: **B**. It structures attack tactics and techniques.

- 6: **B**. Negative tests verify access is blocked.

- 7: **B**. Prompt content is an unreliable authorization mechanism.

- 8: **B**. An attempted incident still needs triage and evidence.

- 9: Require authenticated advisor, assigned student, legitimate task, approved action, logged decision; fail closed. Award 10 points for method, 10 for correct application, 5 for uncertainty and 5 for a cited anchor or case evidence.

- 10: Accept untrusted page attempting a send action and unauthorized user attempting direct tool/API call. Award 10 points for method, 10 for correct application, 5 for uncertainty and 5 for a cited anchor or case evidence.

**Item analysis:** after class, record which distractors attracted learners and revise ambiguous wording. Never infer competence from these ten items alone; use applied artifacts and defense.
