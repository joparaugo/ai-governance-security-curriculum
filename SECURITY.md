# Security policy

This is offline teaching code, not a production AI security product. The toy insecure mode intentionally illustrates an authorization failure and makes no network request.

If you find a vulnerability in the repository or its distribution, contact the repository maintainer using a private GitHub security advisory after the repository is published. Do not place live credentials or personal data in issues. **Before launch:** enable private vulnerability reporting and set an owner and response timeframe; until then the project has no private contact channel.
